# Matthew Paver

I’m a software and AI engineer based in London. I turn difficult operational decisions into tools that show what changed, what was checked and what a person should review next.

My strongest work sits where AI engineering, data quality and solution architecture meet: rules where the answer should be deterministic, evaluation where models can drift, and clear evidence at the decision boundary.

I’m open to AI engineering and solution architecture roles where reliability, evaluation and delivery matter.

## How I work

I use deterministic checks where rules exist, evaluation sets where models can drift, and a person at the decision boundary. Public repositories include a runnable path, fixtures, tests and stated limits.
